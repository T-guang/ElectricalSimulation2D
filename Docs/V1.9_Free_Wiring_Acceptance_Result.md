# V1.9 自由接线通用性验收结果

## 一、验收目标

V1.9 的目标不是新增功能，而是验证 V1 已支持的元件和规则原语在“空画布自由接线”场景下是否仍然成立。

本次验收重点确认：

- 不从图纸集加载标准模板；
- 从空画布手动拖放元件；
- 按端子手动完成接线；
- 手动切换按钮、空开、热继、SQ、KT 等状态；
- 点击“检查当前电路”；
- 对比画布 RUN 状态与检查面板教学化输出；
- 验证当前系统在 V1 支持范围内具备组合式自由接线判定能力。

本次验收不证明系统支持任意电路，不扩展 V1 元件范围，也不引入 V2 动态仿真能力。

## 七、验收结论

当前系统可以在 V1 已支持元件与规则原语范围内，对空画布手动搭建的家庭与工业控制电路进行自由组合式现象判定。

## 八、遗留说明

正反转自由接线测试中，检查面板能够识别正转 / 反转关系，并能提示正反转冲突或互锁异常。

当前画布电机显示层只显示 RUN，未区分“正转 RUN”和“反转 RUN”。该项属于显示层增强，不影响检查面板判定结果，不阻塞 V1.9 封版。

后续可在 V2 显示增强阶段补充：

- 电机正转 / 反转方向视觉标识；
- 电机 RUN 状态的方向标签；
- 检查面板与画布方向显示的一致化提示。
