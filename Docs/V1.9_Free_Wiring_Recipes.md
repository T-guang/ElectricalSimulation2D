# V1.9 自由接线配方卡

本文用于在 Unity 空画布中手动拖放元件、手动接线并执行 V1.9 自由接线通用性验收。不要从图纸集加载标准模板。

本文只记录当前工程已经存在的元件、端子和接线方式，不代表工业现场施工规范，也不替代真实电气安全设计。

## 四、单元级配方

## A-04 接触器线圈独立测试

### 使用元件

- 三相电源：`AC_ThreePhase_Power`
- 接触器 KM：`Contactor_KM_380V`

### 控制回路接线

1. `AC_ThreePhase_Power.L1` → `KM.A1`
2. `KM.A2` → `AC_ThreePhase_Power.L2`

### 操作步骤

1. 完成 A1/A2 接线并点击检查。
2. 删除 `L1 → KM.A1` 或 `KM.A2 → L2` 中任意一根线，再次检查。
3. 可额外测试 A1/A2 同接 L1，确认无有效控制电压。

### 期望结果

- A1/A2 获得 L1-L2 有效控制电压时，KM 线圈得电。
- 任一端断开或 A1/A2 同相时，KM 线圈未得电。

## A-05 接触器主触点动态传播测试

### 使用元件

- 三相电源：`AC_ThreePhase_Power`
- 接触器 KM：`Contactor_KM_380V`
- 三相电机 M：`Motor_ThreePhase_380V`

### 主回路接线

按“模块 M”接线，三相输入可直接取电源 `L1/L2/L3`。

### 控制回路接线

1. `AC_ThreePhase_Power.L1` → `KM.A1`
2. `KM.A2` → `AC_ThreePhase_Power.L2`

### 操作步骤

1. 接通 KM.A1/A2，检查 KM 和电机状态。
2. 断开 KM.A1 或 KM.A2，重新检查。

### 期望结果

- KM 得电后，`L1/T1`、`L2/T2`、`L3/T3` 主触点闭合，电机获得三相并运行。
- KM 失电后，主触点断开，电机停止。

## A-06 接触器 13/14 自锁触点测试

参考模板：`motor_self_hold_control_template.json`

### 使用元件

- 三相电源：`AC_ThreePhase_Power`
- 停止按钮：`Button_Stop_NC`
- 启动按钮：`Button_Start_NO`
- 接触器 KM：`Contactor_KM_380V`
- 三相电机 M：`Motor_ThreePhase_380V`

### 主回路接线

按“模块 M”接线。

### 控制回路接线

1. `Power.L1` → `Stop.11`
2. `Stop.12` → `Start.23`
3. `Start.24` → `KM.A1`
4. `KM.A2` → `Power.L2`
5. `Stop.12` → `KM.13`
6. `KM.14` → `Start.24`

第 5、6 根线使 `KM.13/14` 与启动按钮 `23/24` 并联。

### 操作步骤

1. 停止按钮保持 ON，启动按钮 ON。
2. 确认 KM 与电机运行。
3. 将启动按钮 OFF，观察画布自锁保持与检查面板静态说明。
4. 将停止按钮 OFF。

### 期望结果

- 启动 ON 时 KM 得电，电机运行。
- 启动 OFF 后画布可通过 `13/14` 历史自锁保持；检查面板应说明静态分析边界。
- 停止 OFF 后自锁供电被切断，KM 与电机停止。

## A-07 接触器 21/22 互锁测试

参考模板：`motor_forward_reverse_interlock_template.json`

### 使用元件

- 三相电源：`AC_ThreePhase_Power`
- 停止按钮：`Button_Stop_NC`
- 正转按钮、反转按钮：各一个 `Button_Start_NO`
- 正转接触器、反转接触器：各一个 `Contactor_KM_380V`
- 三相电机：`Motor_ThreePhase_380V`

### 主回路接线

1. 三相 L1/L2/L3 输出分别接两个接触器的 `L1/L2/L3`。
2. 正转 KM：`T1 → M.U`、`T2 → M.V`、`T3 → M.W`。
3. 反转 KM：`T1 → M.W`、`T2 → M.V`、`T3 → M.U`。
4. `Power.PE` → `M.PE`。

### 控制回路接线

1. `Power.L1` → `Stop.11`
2. `Stop.12` → `ForwardButton.23`
3. `Stop.12` → `ReverseButton.23`
4. `ForwardButton.24` → `ReverseKM.21`
5. `ReverseKM.22` → `ForwardKM.A1`
6. `ForwardKM.A2` → `Power.L2`
7. `ReverseButton.24` → `ForwardKM.21`
8. `ForwardKM.22` → `ReverseKM.A1`
9. `ReverseKM.A2` → `Power.L2`

可按当前电气互锁模板补充自锁：

1. `Stop.12` → `ForwardKM.13` → `ForwardKM.14` → `ForwardButton.24`
2. `Stop.12` → `ReverseKM.13` → `ReverseKM.14` → `ReverseButton.24`

### 操作步骤

1. 仅正转按钮 ON。
2. 停止复位后，仅反转按钮 ON。
3. 尝试正反转按钮同时 ON。

### 期望结果

- 单方向操作时，对应接触器得电，另一方向被其 `21/22` 阻止。
- 同时操作时应提示互锁关系、状态异常或正反转风险，不应让两个方向正常同时运行。

## A-08 KT 触点基础测试

### 使用元件

- 三相电源：`AC_ThreePhase_Power`
- 通电延时时间继电器 KT：`Timer_OnDelay_380V`
- 接触器 KM：`Contactor_KM_380V`

### KT 线圈接线

1. `Power.L1` → `KT.A1`
2. `KT.A2` → `Power.L2`

### 延时常开 15/18 测试接线

1. `Power.L1` → `KT.15`
2. `KT.18` → `KM.A1`
3. `KM.A2` → `Power.L2`

### 延时常闭 15/16 测试接线

单独测试时，将上面的 `KT.18 → KM.A1` 改为：

1. `KT.16` → `KM.A1`

### 操作步骤

1. KT 未得电，手动设置 KT ON。
2. 恢复 KT 线圈供电，设置 KT OFF。
3. KT 线圈保持得电，设置 KT ON。
4. 分别观察 15/18 和 15/16 控制的 KM 状态。

### 期望结果

- KT 未得电时，即使 KT ON，也按复位处理：15/16 导通，15/18 断开。
- KT 得电且 OFF：延时未到，15/16 导通，15/18 断开。
- KT 得电且 ON：延时到达，15/16 断开，15/18 导通。

- 检查面板识别为三角形连接，三角运行条件成立。

## B-08 自由制造星三角冲突

## 六、错误接线与防呆配方

## C-01 缺相

### 使用元件

- 可使用 A-05 的普通三相电机回路，或 B-06/B-07 的星三角电机回路。

### 操作步骤

1. 普通三相电机：删除 `KM.T3 → M.W` 或不连接 M.W。
2. 星三角电机：删除 `Power.L3 → Motor.W1`。
3. 点击检查。

### 期望结果

- 检查面板提示缺相。
- 电机不应被判定为正常运行。

## C-02 重复相

### 使用元件

- 三相电源：`AC_ThreePhase_Power`
- 普通三相电机：`Motor_ThreePhase_380V`，或星三角电机：`Motor_StarDelta_380V`

### 接线

普通电机示例：

1. `Power.L1` → `Motor.U`
2. `Power.L1` → `Motor.V`
3. `Power.L3` → `Motor.W`

星三角电机示例：

1. `Power.L1` → `Motor.U1`
2. `Power.L1` → `Motor.V1`
3. `Power.L3` → `Motor.W1`
4. `Motor.U2` → `Motor.V2` → `Motor.W2`

### 期望结果

- 检查面板提示重复相或三相输入异常。
- 电机不应正常运行。

## C-03 普通器件同元件端子互接禁止

### 尝试的非法连接

1. `Contactor_KM_380V.L1` → 同一接触器的 `T1`
2. `Button_Stop_NC.11` → 同一按钮的 `12`
3. `Button_Start_NO.23` → 同一按钮的 `24`
4. `Breaker_3P.P1_IN` → 同一空开的 `P1_OUT`
5. `Fuse_3P.L1_IN` → 同一熔断器的 `L1_OUT`
6. `Timer_OnDelay_380V.15` → 同一 KT 的 `18`
7. `Motor_ThreePhase_380V.U` → 同一电机的 `V`

### 期望结果

- 接线不能成功。
- 不生成隐藏 connection，不保存非法连接。
- 检查面板不把这些端子误认为外部短接。

## C-04 星三角电机同元件跳线允许

### 使用元件

- 星三角电机：`Motor_StarDelta_380V`

### 允许测试的跳线

1. `U2 → V2`
2. `V2 → W2`
3. `U1 → W2`
4. `V1 → U2`
5. `W1 → V2`

### 禁止测试

- `PE` 不参与星形或三角跳线；不要将 `PE` 与任一 U/V/W 端子相连。

### 期望结果

- 六个 U/V/W 端子之间的合法同元件跳线可以创建并可见。
- 跳线可撤销、重做、保存和加载。
- 检查面板能依据实际跳线识别星形、三角或冲突。

## C-05 KT 未得电防呆

### 使用元件

- 三相电源：`AC_ThreePhase_Power`
- KT：`Timer_OnDelay_380V`
- KM2：`Contactor_KM_380V`

### 接线

1. 保持 `KT.A1` 或 `KT.A2` 未连接，使 KT 线圈不得电。
2. `Power.L1` → `KT.15`
3. `KT.18` → `KM2.A1`
4. `KM2.A2` → `Power.L2`

### 操作步骤

1. 手动将 KT 切换为 ON，即 `IsClosed=true`。
2. 点击检查并观察画布。

### 期望结果

- KT 线圈未得电，延时状态按复位处理。
- 15/16 导通，15/18 断开。
- KM2 不得电，不能因为 KT UI 为 ON 而运行。
