## 二、逐项审计

### 1. 电动机点动控制电路

- **模板文件**：`motor_jog_control_template.json`
- **系统实际元件**：
  - 三相交流电源 (`power_3p_1` / `AC_ThreePhase_Power`)
  - 三相断路器 (`breaker_3p_1` / `Breaker_3P`)
  - 三相熔断器 (`fuse_3p_1` / `Fuse_3P`)
  - 交流接触器(380V) (`km_1` / `Contactor_KM_380V`)
  - 三相电动机 (`motor_1` / `Motor_ThreePhase_380V`)
  - 停止按钮 (`stop_1` / `Button_Stop_NC`)
  - 启动按钮 (`start_1` / `Button_Start_NO`)
- **按钮数量**：2 个（停止按钮 + 启动按钮）
- **主回路结构**：电源 -> 断路器 -> 熔断器 -> 接触器主触点 -> 电机
- **控制回路结构**：串联了停止按钮的 NC 触点与启动按钮的 NO 触点。无 KM 自锁接线。
- **关键控制逻辑**：点动控制。按住启动按钮时 KM 线圈得电吸合，电机运行；松开按钮时 KM 发送释放，电机停止。
- **和常见网上图差异**：网上最简原理图通常只有 1 个启动按钮，而无停止按钮。系统为了实现物理元器件布局的规整与复用，采用了“停止按钮（串联） + 启动按钮”的训练版点动回路。
- **风险**：中。学生容易对停止按钮的出现产生疑虑，若直接连接网上原理图可能导致漏接停止按钮。
- **建议处理**：**B 类**（可用网上图，但必须加“系统练习版说明”）。
- **建议“系统练习版说明”文案**：本系统点动电路采用“训练版”双按钮物理布局。控制回路中串接了停止按钮（SB1）以确保与后续连续运行回路布局一致，接线时只需将 SB1（常闭）与 SB2（常开）串联后接至接触器线圈（A1），**不要**接自锁辅助常开触点。

### 5. 按钮互锁正反转控制电路

- **模板文件**：`motor_forward_reverse_control_template.json`
- **系统实际元件**：
  - 三相交流电源 (`power_3p_1` / `AC_ThreePhase_Power`)
  - 三相断路器 (`breaker_3p_1` / `Breaker_3P`)
  - 三相熔断器 (`fuse_3p_1` / `Fuse_3P`)
  - 交流接触器(380V) (`km_forward` / `Contactor_KM_380V`)
  - 交流接触器(380V) (`km_reverse` / `Contactor_KM_380V`)
  - 三相电动机 (`motor_1` / `Motor_ThreePhase_380V`)
  - 停止按钮 (`stop_1` / `Button_Stop_NC`)
  - 启动按钮 (`forward_button_1` / `Button_Start_NO`)
  - 启动按钮 (`reverse_button_1` / `Button_Start_NO`)
- **按钮数量**：3 个
- **主回路结构**：换相正反转主电路。
- **控制回路结构**：此电路**没有**自锁支路（未使用 13/14 触点），也**没有**使用复合按钮的按钮互锁。它仅使用了正反转接触器的辅助常闭触点 21/22 进行电气互锁。
- **关键控制逻辑**：电气互锁的**点动**正反转。按住正转按钮正转，按住反转按钮反转，不能自锁，且由于接触器常闭互锁，正反转不能同时动作。
- **和常见网上图差异**：**巨大差异**。网上名为“按钮互锁正反转电路”均有**自锁**和**复合按钮的按钮互锁**。而该系统模板实质是“电气互锁的点动正反转控制”。
- **风险**：高。如果不重命名模板或加极强说明，会与网上的经典“按钮互锁”原理图完全对不上，学生根本无法完成接线。
- **建议处理**：**C 类**（不建议直接用网上图，建议后续重绘或修订模板）。
- **建议“系统练习版说明”文案**：**【注意】** 当前系统模板实际为“电气互锁点动正反转电路”。它**不包含自锁**且**未采用复合按钮互锁**，接线时只需将启动按钮与对应接触器的常闭辅助触点串联，无需连接 13/14 自锁端子。

- **关键控制逻辑**：两电机延时启动。KM2 线圈接通后，KM2 常开辅助触点也接入自锁，确保可靠吸合。
- **和常见网上图差异**：极小。基本符合所有电气控制标准原理图。
- **风险**：低。
- **建议处理**：**A 类**（可直接用网上原理图）。

### 10. 星三角降压启动控制电路

- **模板文件**：`motor_star_delta_start_template.json`
- **系统实际元件**：
  - 三相交流电源 (`power_3p_1` / `AC_ThreePhase_Power`)
  - 三相断路器 (`breaker_3p_1` / `Breaker_3P`)
  - 三相熔断器 (`fuse_3p_1` / `Fuse_3P`)
  - 交流接触器(380V) (`km_main` / `Contactor_KM_380V`, `km_star` / `Contactor_KM_380V`, `km_delta` / `Contactor_KM_380V`)
  - 时间继电器(380V) (`kt_timer` / `Timer_OnDelay_380V`)
  - 星接中点排 (`star_point` / `TerminalBlock_2H`)
  - 星三角六端子电动机 (`motor_star_delta` / `Motor_StarDelta_380V`)
  - 停止按钮 (`stop_1` / `Button_Stop_NC`)
  - 启动按钮 (`start_1` / `Button_Start_NO`)
- **按钮数量**：2 个
- **主回路结构**：KM_main 接入三相绕组首端，KM_star 封尾，KM_delta 形成闭合三角接线。
- **控制回路结构**：启动时，KM_main 与 KM_star 同时吸合，时间继电器 KT 开始计时。延时结束后，KT 延时常闭断开 KMY（星接），延时常开闭合接通 KMD（角接）。KMY 和 KMD 间有电气常闭互锁。
- **关键控制逻辑**：延时降压星三角启动。
- **和常见网上图差异**：中。原理完全一致。但在实物连线中，网上原理图对于星接的“短接中点”通常只画一条线；而在本系统中，学生需要将 KM_star 的输出端连接到专门的端子排（`star_point`）实现并线。此外电机必须是专门的六端子电机。
- **风险**：中。如果不加以说明，学生可能对“封中点排（star_point）”和“六端子异步电机”的接法无从下手。
- **建议处理**：**B 类**（可用网上图，但必须加“系统练习版说明”）。
- **建议“系统练习版说明”文案**：本星三角启动采用六端子电机。星形接触器封中点在 Unity 仿真中需要连接到星接端子排（star_point）上，同时星形接触器与角形接触器线圈之间必须连接电气常闭互锁触点防止短路。

## 三、建议为图纸集增加的说明字段

为在前端统一优雅展示，建议在图纸集的数据载体中（如 Catalog JSON 中）为对应的模板配置以下两个属性：

1. `referenceDiagramNote`（网上原理图参考说明）：用于提醒网上的原理图与系统实物可能存在的画法简化或线号差异。
