# 图纸集原理图资源制作规范

## 1. 页面定位

- 图纸集展示的是**电路原理图**，用于帮助学生理解回路结构、元件关系和控制逻辑。
- 仿真广场展示的是**Unity 模板截图**，用于展示系统内置案例的实际练习画面。
- 图纸集与仿真广场必须严格区分，图纸集**不能直接使用 Unity 模板截图**代替原理图。

## 2. 图片来源策略

### A 类模板

- 可以直接参考网上常见原理图进行重描、清晰化、统一裁剪。
- 系统详情页只需要显示普通原理图说明，不需要额外高风险提示。

### B 类模板

- 可以使用网上原理图作为底图参考，但必须结合系统练习版说明处理。
- 如果无法准确改成与系统训练版完全一致，不强制重画电路结构，可由系统详情页显示练习版差异说明。
- **不要为了完全匹配网上图而修改系统模板连接逻辑。**

## 3. 不要求美工从 0 画电路

- 美工不需要自行判断电路对错。
- 美工不需要理解全部电气原理后再决定元件增删。
- **不允许**自行增加、删除或替换按钮、接触器、热继电器、时间继电器、行程开关、电机等关键元件。
- 如果发现网上图与系统练习版不一致，应记录给策划/程序，由系统详情说明解决，不通过改模板解决。

## 4. 推荐制作方式

每张图建议同时参考以下三类资料：

1. 网上参考原理图；
2. Unity 模板截图；
3. 系统练习版说明。

美工主要负责：

- 按网上原理图重描线条；
- 统一字体和字号；
- 统一留白和裁切边界；
- 去除水印；
- 提高清晰度；
- 保持黑白原理图风格；
- 必要时根据系统练习版说明增加少量注释框。

## 5. 输出尺寸与风格

- 缩略图建议尺寸：`1200 x 675`，16:9。
- 详情图建议尺寸：`1600 x 900` 或 `1920 x 1080`。
- 背景：白色或透明。
- 线条：黑色。
- 字体：黑体类或清晰无衬线字体。
- 保持黑白教学原理图风格，不使用花哨颜色。
- 不要加入 Unity 仿真元件截图、按钮贴图或界面控件截图。

## 7. B 类模板特别说明

以下 5 个模板属于 B 类，允许参考网上原理图，但系统内必须显示“练习版说明”：

1. 电动机点动控制电路
2. 热继电器保护电动机控制电路
3. 电动机正反转控制电路
4. 自动往返电动机控制电路
5. 星三角降压启动控制电路

处理原则：

- 可先用网上参考图重描；
- 允许保持教学层面的简化画法；
- 若系统训练版在按钮数量、热继接入方式、星点封接、限位换向方式上存在差异，应由系统详情页补充说明；
- **不要为了追求和网上图完全一致而修改系统模板。**

## 8. 交付检查清单

出图前请自查：

1. 图纸是原理图，不是 Unity 截图；
2. 线条、文字清晰，缩略图缩小后仍可辨认；
3. 没有水印、二维码、站点 Logo；
4. 命名符合约定；
5. B 类模板已告知程序需要显示“系统练习版说明”；
6. 没有擅自增删关键元件；
7. 黑白风格统一，便于教学阅读。
