# V2.3.6.4 结构级接线校验负向扰动测试集

## 1. 测试集目标

本测试集用于固定 V2.3.6.1 至 V2.3.6.3 已支持的接线校验规则，作为后续结构级接线校验、参数估算和运行逻辑修改前后的人工回归基线。

目标：

- 正常模板不误报。
- 每条已支持 RuleId 都有正向触发用例。
- 每条已支持 RuleId 都有防误报用例。
- 复杂模板不被错误归类为其它结构错误。
- 已知边界明确记录，避免把未支持能力误判为回归失败。
- 后续可逐步迁移为 Editor Test 或 PlayMode Test。

本测试集不引入新规则，不改变运行层，不改变模板 JSON，不改变参数估算公式。

| `REVERSING_CONTACTOR_CONFLICT` | Error | 同一台电机的正反转接触器出现互锁冲突或同时吸合风险。 | 必须依赖 `ReversingPairScopeHelper` 识别可靠正反转 pair；不扫描任意两个 KM。 |

## 7. 已知边界

1. `SELF_HOLDING_BRANCH_INCOMPLETE`
   - KM `13/14` 全部删除时不报。
   - 原因：自由接线下该结构可视为退化点动控制，不能把点动误报为自锁缺失。
   - 若未来练习题明确要求“连续运行”，应由练习目标比对层另行提示。

2. `THERMAL_RELAY_CONTROL_BYPASSED`
   - 触发时可能叠加 `MOTOR_MISSING_PHASE`。
   - 这是热继 OFF 或主回路断开带来的次生错误噪声，后续可做 Issue 优先级降噪。
   - 当前不作为阻塞。

3. `REVERSING_CONTACTOR_CONFLICT`
   - 不以两个 KM 最终同时得电作为唯一条件。
   - 运行层会阻止危险状态继续传播，因此校验层读取互锁冲突证据。
   - 必须依赖 `ReversingPairScopeHelper`，不能扫描任意两个 KM。

4. `ReversingPairScopeHelper`
   - 只支持普通三相电机正反转。
   - 不支持 `Motor_StarDelta_380V`。
   - 多台 Motor 或多个可靠 pair 存在歧义时保守返回空。
   - 不依赖实例名、显示名或模板名判断正转/反转。

5. 星三角端子不变量
   - `STAR_DELTA_PARTIAL_STARPOINT_SHORT` 与 `STAR_DELTA_INPUT_TERMINAL_SHORT` 只使用静态直接导线图。
   - 不穿过接触器、按钮、KT、热继、空开、熔断器、端子排或电机内部连接。

6. 参数计算
   - 当前保留教学估算。
   - 不做 MNA / ngspice。
   - 结构级校验 Issue 不改变参数估算公式和运行层状态。

2. 按用例生成扰动导线或删除指定导线。
3. 调用 `CircuitStateAnalyzer` 与 `CircuitValidationService`。
4. 断言指定 RuleId 存在或不存在。
5. 输出机器可读测试报告。

优先自动化顺序：

1. 星三角端子短接：
   - `STAR_DELTA_PARTIAL_STARPOINT_SHORT`
   - `STAR_DELTA_INPUT_TERMINAL_SHORT`
2. 停止按钮旁路：
   - `STOP_BUTTON_BYPASSED`
3. 热继旁路：
   - `THERMAL_RELAY_CONTROL_BYPASSED`
4. 自锁支路不完整：
   - `SELF_HOLDING_BRANCH_INCOMPLETE`
5. 正反转冲突：
   - `REVERSING_CONTACTOR_CONFLICT`

本轮不强行自动化，避免为了测试夹具引入新的运行层或模板扰动风险。
