## 当前系统定位

本项目当前是教学级电路现象判定系统，不是工业级物理仿真器。

系统以元件端子、导线拓扑、开关状态、线圈状态和动态触点关系为基础，解释 V1 已支持电路中的亮灯、停止、运行、正反转、自锁、互锁、顺序启动和星三角连接等现象。

## 当前边界

- 当前不是完全任意电路通用；
- 当前属于模板覆盖型通用基本合格；
- 自由接线型通用需要 V1.9 专项验收；
- KT 目前是手动模拟延时，不是真实秒级计时；
- 自动往返目前依赖手动切换 SQ 状态，不是真实虚拟运动；
- 当前不做真实电压、电流、功率、转矩、转速、启动电流、保护动作曲线；
- 检查面板是静态拓扑分析，不读取画布历史 RUN；
- 画布 RUN 可能包含历史自锁保持状态；
- 自由接线测试只能证明当前 V1 已支持元件和规则范围内的通用性，不能证明系统支持任意工业电路。
