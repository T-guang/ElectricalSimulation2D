# V2.3.8.4 规则体系封口审计

## 1. 审计范围与结论

本轮只做规则体系盘点，不新增 RuleId，不修改现有触发条件，不调整模板 JSON，不改 UI，不做高亮、验电笔、万用表或真实电压电流求解。

当前系统在校验层共识别到 **23 条 RuleId**。其中本轮重点审计 16 条上线前核心规则：

1. `POWER_POTENTIAL_CONFLICT`
2. `LIVE_TO_PE_FAULT`
3. `NEUTRAL_PE_MISUSE`
4. `COIL_VOLTAGE_MISMATCH`
5. `BREAKER_OR_FUSE_BYPASSED`
6. `MOTOR_CONTACTOR_BYPASSED`
7. `REVERSING_INTERLOCK_MISSING`
8. `THERMAL_RELAY_CONTROL_BYPASSED`
9. `THERMAL_RELAY_MAIN_CIRCUIT_BYPASSED`
10. `TIMER_CONTROL_BYPASSED`
11. `STOP_BUTTON_BYPASSED`
12. `SELF_HOLDING_BRANCH_INCOMPLETE`
13. `REVERSING_CONTACTOR_CONFLICT`
14. `STAR_DELTA_PARTIAL_STARPOINT_SHORT`
15. `STAR_DELTA_INPUT_TERMINAL_SHORT`
16. `COMPLEX_LOOP_OR_UNSUPPORTED_TOPOLOGY`

审计结论：

- **可直接作为上线前保留规则的 A / B 类规则：14 条**
- **模板倾向、建议继续强化回归的 C 类规则：2 条**
- **当前 16 条规则中未发现必须下线的 D 类规则**
- **当前明显缺少 Editor 自动化测试的重点规则：2 条**
  - `STAR_DELTA_PARTIAL_STARPOINT_SHORT`
  - `STAR_DELTA_INPUT_TERMINAL_SHORT`

## 4. 逐条详细说明

### 4.1 `POWER_POTENTIAL_CONFLICT`

- **触发条件**：`PowerPotentialValidationHelper` 先构建 wire-only 静态导线图，再按连通组收集电源输出端电位标签。如果同一导线组内出现 2 个以上非 PE 电位，则报错。
- **依赖**：
  - `PowerPotentialValidationHelper`
  - 电源/电能表端子角色与端子 ID（`L/L1/L2/L3/N/PE`）
  - `TopologyTraversalLimits`
- **不依赖模板名，不依赖实例名**。
- **本质依据**：元件类型 + 端子角色 + 静态导线拓扑。
- **Editor 测试**：有。覆盖 L-N、L1-L2、L2-L3、L1-L3，且验证灯泡、电机正常接线不误报。
- **已知边界**：第一版只做 wire-only 直接冲突，不穿过负载、不计算真实短路电流。
- **结论**：稳定，建议保留。

### 4.2 `LIVE_TO_PE_FAULT`

- **触发条件**：同一 wire-only 静态导线组内同时出现任一 live 电位和 `PE`。
- **依赖**：`PowerPotentialValidationHelper`
- **不依赖模板名 / 实例名**。
- **测试**：有。覆盖 `L-PE` 和 `L1/L2/L3-PE`。
- **边界**：不做复杂漏电流推导，只识别直接混接。
- **结论**：稳定，建议保留。

### 4.3 `NEUTRAL_PE_MISUSE`

- **触发条件**：同一 wire-only 静态导线组内同时出现 `N` 和 `PE`。
- **Severity**：保持 `Warning` 是合理的，不建议升级为 `Error`。
- **依赖**：`PowerPotentialValidationHelper`
- **测试**：有。
- **边界**：不讨论真实配电系统接地点，只针对教学自由接线误用给提醒。
- **结论**：稳定，建议保留。

### 4.4 `COIL_VOLTAGE_MISMATCH`

- **触发条件**：
  - 先识别支持的控制线圈（当前主要是 `Contactor_KM_220V / 380V`、`Timer_OnDelay_220V / 380V`）。
  - 再通过 analyzer 电压标签和 `ActualSupplyVoltageResolver` 判断 A1/A2 实际是 220V 单相还是 380V 线电压。
  - 220V 线圈接 380V 时报 `Error`；380V 线圈接 220V 时报 `Warning`。
- **注意**：当前**不是**真实分压判断，也不是多线圈串联精确电压求解。
- **测试**：有。
- **边界**：判断不可靠时直接跳过，不误报。
- **结论**：稳定，建议保留。

### 4.5 `BREAKER_OR_FUSE_BYPASSED`

- **触发条件**：保护器件被判定为断开，但其输出端仍带电。
- **依赖**：
  - `ProtectionBypassValidationHelper`
  - analyzer 对端子电压的判定
- **测试**：有。覆盖断开的空开、断开的熔断器、正常回路不误报。
- **边界**：只对可识别输出端的保护器件有效。
- **结论**：稳定，建议保留。

### 4.6 `MOTOR_CONTACTOR_BYPASSED`

- **触发条件**：普通三相电机 `Motor_ThreePhase_380V` 的 `U/V/W` 通过静态导线直接接入三相电源，同时画布中存在受支持接触器结构。
- **依赖**：`ProtectionBypassValidationHelper`
- **不依赖模板名 / 实例名**，但强依赖“普通三相电机 + 支持接触器”的工业结构。
- **测试**：有。覆盖直接供电、经 KM 主触点、带热继、星三角不误报。
- **边界**：
  - 不适用于星三角六端子电机。
  - 如果用户有意构造“非接触器直接启动”教学场景，这条规则会更偏教学规范而非纯电气事实。
- **结论**：保留，但属于半通用规则，建议持续手工回归工业模板。

### 4.7 `REVERSING_INTERLOCK_MISSING`

- **触发条件**：`ReversingPairScopeHelper` 能可靠识别一组正反转接触器对同一台普通三相电机的 forward/reverse 映射，但未识别到：
  - 21/22 电气互锁；或
  - 复合按钮互锁。
- **依赖**：
  - `ProtectionBypassValidationHelper`
  - `ReversingPairScopeHelper`
- **测试**：有。覆盖无互锁、电气互锁、双重联锁、两电机顺序、星三角。
- **边界**：
  - 第一版只认“同一台普通三相电机 + 2 个可靠映射接触器”。
  - 多 pair 时 helper 直接放弃可靠识别。
- **结论**：稳定，建议保留，`Warning` 合理。

### 4.8 `THERMAL_RELAY_CONTROL_BYPASSED`

- **触发条件**：热继控制触点 95/96 断开，但通过 `ThermalRelayProtectionScopeHelper` 识别到的上游接触器线圈仍得电。
- **依赖**：
  - `ThermalRelayProtectionScopeHelper`
  - analyzer 线圈得电状态
- **测试**：有，且在 `TopologySafetyTests` 与 `ThermalTimerBypassValidationTests` 中双覆盖。
- **边界**：要求可靠识别“唯一热继 + 唯一上游接触器 + 保护电机”。
- **结论**：稳定，建议保留。

### 4.9 `THERMAL_RELAY_MAIN_CIRCUIT_BYPASSED`

- **触发条件**：可靠识别出 `KM -> FR -> Motor_ThreePhase_380V` 应成立，但实际电机供电绕开了热继主回路。
- **依赖**：
  - `ProtectionBypassValidationHelper`
  - `ThermalRelayProtectionScopeHelper`
- **测试**：有。覆盖正常热继主回路、主回路旁路、控制旁路不混淆、双电机、星三角不误报。
- **边界**：
  - 第一版只支持普通三相电机。
  - 不支持星三角电机复杂主回路热继结构。
- **结论**：建议保留。

### 4.10 `TIMER_CONTROL_BYPASSED`

- **触发条件**：支持的通电延时 KT 仍处于 `Timing`，但其 `15/18` 所控制的接触器线圈已经提前得电。
- **依赖**：
  - `TimerControlBypassValidationHelper`
  - analyzer 对定时器状态与线圈状态的判定
- **测试**：有。覆盖顺序启动正常 / 提前得电 / 到时得电、星三角正常 / 提前三角、连续运行、正反转、自动往返不误报。
- **边界**：
  - 第一版只支持可靠识别的 KT 控制关系。
  - 不做完整顺序控制目标比对，不做真实时间电流求解。
- **结论**：建议保留。

### 4.11 `STOP_BUTTON_BYPASSED`

- **触发条件**：
  - 画布中恰好只有 1 个“纯停止按钮” `Button_Stop_NC`
  - 按钮当前断开
  - 同时至少有一个受支持控制线圈仍得电
- **依赖**：`CircuitValidationService` 内部规则 + analyzer 线圈状态
- **测试**：有，位于 `TopologySafetyTests`。
- **边界**：
  - 明显依赖“单停止按钮”假设。
  - 多停止按钮、复合按钮、更复杂控制域目前跳过。
- **误报风险**：在所有核心规则里偏高。
- **结论**：建议保留，但归为 C 类，并优先补多模板自动回归。

### 4.12 `SELF_HOLDING_BRANCH_INCOMPLETE`

- **触发条件**：
  - helper 只接受“单停止按钮 + 单启动按钮 + 单接触器”
  - 没有复合按钮、没有星三角电机、没有自锁按钮
  - 13/14 有外接线尝试，但未形成跨启动按钮的有效并联支路
- **依赖**：`SelfHoldingBranchValidationHelper`
- **测试**：有，位于 `TopologySafetyTests`。
- **边界**：
  - 这是当前最明显的结构化、模板倾向规则之一。
  - 主动跳过复杂控制结构是优点，也是覆盖边界。
- **误报风险**：中到高，但因为保守跳过复杂结构，当前仍可上线。
- **结论**：保留，建议后续补单元测试和多模板自动回归。

### 4.13 `REVERSING_CONTACTOR_CONFLICT`

- **触发条件**：
  - `ReversingPairScopeHelper` 可靠识别到正反转 pair；
  - analyzer 判断两个接触器线圈同时得电，或都处于 `InterlockConflict`。
- **依赖**：
  - `ReversingPairScopeHelper`
  - analyzer 线圈/互锁冲突状态
- **测试**：有，位于 `TopologySafetyTests`。
- **边界**：只对可靠 pair 生效，pair 不明确时不报。
- **结论**：建议保留。

### 4.14 `STAR_DELTA_PARTIAL_STARPOINT_SHORT`

- **触发条件**：`Motor_StarDelta_380V` 的 `U2/V2/W2` 之间出现部分短接（1 或 2 对），而不是完整星点封接。
- **依赖**：`MotorPhaseValidationHelper` 的直接导线连通判定。
- **测试**：**当前未发现专门 Editor 测试。**
- **边界**：
  - 只检查静态直接短接不变量。
  - 不做星三角整体运行时序判断。
- **结论**：规则本身建议保留，但这是当前最需要补测试的点之一。

### 4.15 `STAR_DELTA_INPUT_TERMINAL_SHORT`

- **触发条件**：`Motor_StarDelta_380V` 的 `U1/V1/W1` 输入端任意两端存在直接短接。
- **依赖**：`MotorPhaseValidationHelper`
- **测试**：**当前未发现专门 Editor 测试。**
- **边界**：只做静态直接短接不变量，不涉及星接/角接控制逻辑。
- **结论**：规则本身建议保留，但需补 Editor 测试。

### 4.16 `COMPLEX_LOOP_OR_UNSUPPORTED_TOPOLOGY`

- **触发条件**：任一 helper 或遍历器触发 `TopologyTraversalLimits` 的 steps / nodes / edges 预算上限。
- **依赖**：
  - `TopologyTraversalLimits`
  - 触发它的具体 helper（`MotorPhaseValidationHelper`、`PowerPotentialValidationHelper`、`ProtectionBypassValidationHelper`、`TimerControlBypassValidationHelper`、`SelfHoldingBranchValidationHelper`、`ReversingPairScopeHelper`、`ThermalRelayProtectionScopeHelper`）
- **测试**：有，位于 `TopologySafetyTests`。
- **边界**：这是防卡死保护，不是电气真值判断。
- **结论**：必须保留。

## 5. 通用性分类结果

### A. 通用规则（6 条）

1. `POWER_POTENTIAL_CONFLICT`
2. `LIVE_TO_PE_FAULT`
3. `NEUTRAL_PE_MISUSE`
4. `COIL_VOLTAGE_MISMATCH`
5. `BREAKER_OR_FUSE_BYPASSED`
6. `COMPLEX_LOOP_OR_UNSUPPORTED_TOPOLOGY`

特点：

- 核心依赖元件类型、端子角色、静态拓扑和 analyzer 电压/线圈状态；
- 不依赖模板名；
- 可用于自由接线沙盒。

### B. 半通用规则（6 条）

1. `MOTOR_CONTACTOR_BYPASSED`
2. `REVERSING_INTERLOCK_MISSING`
3. `THERMAL_RELAY_CONTROL_BYPASSED`
4. `THERMAL_RELAY_MAIN_CIRCUIT_BYPASSED`
5. `TIMER_CONTROL_BYPASSED`
6. `REVERSING_CONTACTOR_CONFLICT`
7. `STAR_DELTA_PARTIAL_STARPOINT_SHORT`
8. `STAR_DELTA_INPUT_TERMINAL_SHORT`

说明：严格说这里是 **8 条**。它们都不依赖模板名，但适用对象明显偏向工业控制结构、正反转、星三角、热继或 KT 延时。

### C. 模板倾向规则（2 条）

1. `STOP_BUTTON_BYPASSED`
2. `SELF_HOLDING_BRANCH_INCOMPLETE`

原因：

- 都明显依赖“单按钮 / 单接触器 / 简化控制域”结构前提；
- 不依赖模板名，但依赖典型训练电路形态；
- 当前通过“识别不到就跳过”的方式降低误报。

### D. 当前不建议上线规则（0 条）

本轮重点 16 条中，**没有必须临时关闭**的规则。

| 通用电源安全规则测试 | `POWER_POTENTIAL_CONFLICT`、`LIVE_TO_PE_FAULT`、`NEUTRAL_PE_MISUSE`、`COIL_VOLTAGE_MISMATCH` |
| 拓扑安全与负向扰动测试 | `COMPLEX_LOOP_OR_UNSUPPORTED_TOPOLOGY`、`STOP_BUTTON_BYPASSED`、`THERMAL_RELAY_CONTROL_BYPASSED`、`SELF_HOLDING_BRANCH_INCOMPLETE`、`REVERSING_CONTACTOR_CONFLICT` |
| 保护旁路与正反转互锁缺失测试 | `BREAKER_OR_FUSE_BYPASSED`、`MOTOR_CONTACTOR_BYPASSED`、`REVERSING_INTERLOCK_MISSING` |
| 热继主回路与时间继电器旁路测试 | `THERMAL_RELAY_MAIN_CIRCUIT_BYPASSED`、`TIMER_CONTROL_BYPASSED`，并再次交叉覆盖 `THERMAL_RELAY_CONTROL_BYPASSED` |

### 6.3 当前缺测试规则

本轮 16 条核心规则中，当前明确缺少专门 Editor 自动化测试的是：

1. `STAR_DELTA_PARTIAL_STARPOINT_SHORT`
2. `STAR_DELTA_INPUT_TERMINAL_SHORT`

建议下一轮补两个小型 Editor 测试，不需要改规则本身。

## 7. 正常模板误报风险审计

### 7.1 家庭 8 张模板

整体风险较低。家庭模板与当前核心规则的耦合点主要集中在：

- `POWER_POTENTIAL_CONFLICT`
- `LIVE_TO_PE_FAULT`
- `NEUTRAL_PE_MISUSE`
- `COIL_VOLTAGE_MISMATCH`
- `BREAKER_OR_FUSE_BYPASSED`

这些规则大多是 A 类通用规则，误报风险相对可控。

### 7.2 工业 10 张模板

风险更高，主要集中在以下结构：

- 正反转系列：
  - `REVERSING_INTERLOCK_MISSING`
  - `REVERSING_CONTACTOR_CONFLICT`
- 热继保护：
  - `THERMAL_RELAY_CONTROL_BYPASSED`
  - `THERMAL_RELAY_MAIN_CIRCUIT_BYPASSED`
- 顺序启动 / 星三角：
  - `TIMER_CONTROL_BYPASSED`
  - `STAR_DELTA_PARTIAL_STARPOINT_SHORT`
  - `STAR_DELTA_INPUT_TERMINAL_SHORT`
- 连续运行 / 点动连续：
  - `STOP_BUTTON_BYPASSED`
  - `SELF_HOLDING_BRANCH_INCOMPLETE`

### 7.3 风险最高的模板

1. 星三角降压启动控制电路  
   原因：涉及六端子电机、星点封接、KT 延时、星三角切换，多规则叠加且缺少两条星三角不变量测试。

2. 电动机正反转控制电路 / 电气互锁正反转 / 双重联锁正反转  
   原因：`REVERSING_INTERLOCK_MISSING` 与 `REVERSING_CONTACTOR_CONFLICT` 都作用在这一族结构上。

3. 两电机时间继电器顺序启动控制电路  
   原因：`TIMER_CONTROL_BYPASSED`、`COIL_VOLTAGE_MISMATCH`、保护规则都可能叠加。

4. 热继电器保护电动机控制电路  
   原因：主回路热继与 95/96 控制保护需要同时成立。

### 7.4 最容易误报的规则

按当前实现与结构假设，误报风险从高到低大致为：

1. `STOP_BUTTON_BYPASSED`
2. `SELF_HOLDING_BRANCH_INCOMPLETE`
3. `MOTOR_CONTACTOR_BYPASSED`
4. `TIMER_CONTROL_BYPASSED`
5. `THERMAL_RELAY_MAIN_CIRCUIT_BYPASSED`

说明：

- 前两条主要是结构前提强；
- 中间三条虽然有保守条件，但都带有明显工业训练意图。

### 7.5 是否建议进一步手动回归

建议，尤其是以下模板：

1. 连续运行
2. 点动 + 连续
3. 热继保护
4. 电动机正反转控制电路
5. 电气互锁正反转控制电路
6. 按钮和接触器双重联锁正反转控制电路
7. 两电机时间继电器顺序启动
8. 星三角降压启动

### 7.6 是否建议增加 Editor 自动化测试

建议，优先级如下：

1. `STAR_DELTA_PARTIAL_STARPOINT_SHORT`
2. `STAR_DELTA_INPUT_TERMINAL_SHORT`
3. 18 张标准模板的“批量无误报 smoke test”
4. `STOP_BUTTON_BYPASSED` 多停止按钮 / 复合停止按钮负例
5. `SELF_HOLDING_BRANCH_INCOMPLETE` 多接触器与复合按钮负例

## 8. 已知边界

1. 当前系统**不做 MNA**，不做真实电流、电压、分压、节点电势法求解。
2. `COIL_VOLTAGE_MISMATCH` 只做可靠电源类型识别，不做多线圈串联分压精确判断。
3. `MOTOR_CONTACTOR_BYPASSED` 第一版只支持普通三相电机，不支持星三角六端子电机。
4. `THERMAL_RELAY_MAIN_CIRCUIT_BYPASSED` 第一版只支持普通三相电机，不支持星三角主回路热继复杂结构。
5. `TIMER_CONTROL_BYPASSED` 第一版只支持可可靠识别的 KT -> KM 关系，不做完整顺序目标比对。
6. `STOP_BUTTON_BYPASSED` 依赖“唯一纯停止按钮”假设。
7. `SELF_HOLDING_BRANCH_INCOMPLETE` 依赖“单停止按钮 + 单启动按钮 + 单接触器”假设。
8. `REVERSING_INTERLOCK_MISSING` 与 `REVERSING_CONTACTOR_CONFLICT` 都只在 `ReversingPairScopeHelper` 可靠识别 pair 时生效。
9. `COMPLEX_LOOP_OR_UNSUPPORTED_TOPOLOGY` 是防卡死保护，不等价于精确电气结论。

- 防卡死保护已在拓扑压力测试中验证；
- 当前最大短板不再是“有没有规则”，而是“学生能否看懂报告”与“个别规则是否还缺补充测试”。
