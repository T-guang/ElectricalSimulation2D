# 当前支持电路能力矩阵

## 一、系统定位

当前系统不是任意电路通用仿真器，而是在 V1 已支持元件和规则原语范围内具备自由接线组合式判定能力的教学级电路现象判定系统。

它擅长回答：

- 当前接线下电源标签是否能传播到目标端子；
- 线圈是否得电；
- 接触器主触点是否应闭合；
- 辅助触点、自锁、互锁、KT、SQ 是否影响控制回路；
- 电机是否具备运行条件；
- 星三角连接是否成立或冲突；
- 常见错误接线是否应提示风险。

它当前不负责真实物理量计算，不等同于工业级电磁暂态、电机动力学或保护动作仿真器。

| 电能表 | 模板内基础接线路径识别 |

## 三、当前支持的触点语义

| 触点 / 端子 | 支持语义 |
|---|---|
| 启动按钮 23/24 | 按钮 ON 时导通，OFF 时断开 |
| 停止按钮 11/12 | 按钮 ON 时导通，OFF 时断开 |
| 接触器 A1/A2 | 有效控制电压下线圈得电 |
| 接触器 L1/T1、L2/T2、L3/T3 | 线圈得电时主触点闭合 |
| 接触器 13/14 | 线圈得电时常开辅助触点闭合，用于自锁 |
| 接触器 21/22 | 线圈得电时常闭辅助触点断开，用于互锁 |
| 热继 95/96 | 热继正常时导通，动作 / OFF 时断开 |
| SQ 11/12 | SQ 未触发时导通，触发时断开 |
| SQ 23/24 | SQ 未触发时断开，触发时导通 |
| KT A1/A2 | 有效控制电压下 KT 线圈得电 |
| KT 15/16 | KT 未得电或延时未到时导通，延时到达时断开 |
| KT 15/18 | KT 线圈得电并进入 Elapsed 后导通，否则断开 |

## 四、当前支持的电路现象

### 家庭电路

- 单开单控灯亮 / 不亮；
- 双控照明拨位组合形成 / 未形成完整火线路径；
- 空气开关控制照明；
- 灯泡与电风扇并联控制；
- 双灯分别控制；
- 电能表基础照明路径；
- 多负载并联中某一路开关 OFF 时只影响对应负载。

### 工业电路

- 点动控制；
- 连续运行自锁；
- 热继保护切断控制回路；
- 正反转控制；
- 电气互锁与双重联锁；
- 自动往返中 SQ 触发方向切换；
- KT 真实通电延时计时；
- 两电机时间继电器顺序启动；
- 星三角电机星形连接；
- 星三角电机三角连接；
- 星三角冲突危险提示；
- 自由接线下上述规则原语的组合判定。

## 七、判断新电路是否属于当前通用范围

一个新电路可以纳入当前 V1 通用判定范围，需要同时满足：

1. 使用当前 Data asset 中已支持的元件；
2. 接线只依赖当前已支持的端子语义；
3. 控制逻辑可以由以下原语组合描述：
   - 电源标签传播；
   - 开关 / 按钮通断；
   - 接触器线圈得电；
   - 接触器主触点动态闭合；
   - 13/14 自锁；
   - 21/22 互锁；
   - 热继 95/96 保护触点；
   - SQ 11/12、23/24；
   - KT 15/16、15/18 通电延时自动切换；
   - 三相电机相序 / 缺相 / 重复相；
   - 星三角六端子连接关系；
4. 不要求真实电流、电压、功率、转矩、时间延迟或机械运动模型；
5. 不要求检查面板读取画布历史 RUN 状态。

如果一个新电路需要真实时间、真实参数、机械位置、PLC 程序、模拟量测量或未定义元件，则应归入 V2 或更后续阶段。

## 八、边界说明

- 检查面板是静态拓扑与规则分析，不读取画布历史 RUN。
- 画布 RUN 可以包含历史自锁保持状态。
- 当两者看似不一致时，需要根据“冷启动状态”与“历史运行保持状态”区分解释。
- 当前系统用于教学现象判断，而不是工业级物理仿真。
