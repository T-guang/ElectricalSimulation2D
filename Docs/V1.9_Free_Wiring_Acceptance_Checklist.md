# V1.9 自由接线通用性验收清单

## 一、验收目标

V1.9 不是新增功能阶段，而是自由接线通用性验收阶段。

目标是在不加载标准模板的情况下，从空画布手动拖放 V1 已支持元件并完成接线，验证系统能否基于端子拓扑、触点状态、线圈得电、主触点动态传播、辅助触点、KT、SQ、星三角连接关系，正确判断当前 V1 支持范围内的电路现象。

本阶段不证明系统能识别任意电路，只验证当前 V1 已支持元件和规则范围内的自由搭建电路。

## 二、测试原则

- 不从图纸集加载模板；
- 从空画布手动拖元件；
- 手动完成接线；
- 手动切换按钮、开关、空开、KT、SQ、热继等状态；
- 点击“检查当前电路”；
- 同时记录画布 RUN 状态和检查面板文本；
- 每个测试项记录：通过 / 失败 / 现象 / 备注 / 截图路径；
- 每次测试前清空画布或重置运行状态，避免历史自锁状态影响下一项；
- 失败项必须分类为 Bug / 已知边界 / 暂不支持 / 需要复测。

## 七、V1.9 通过标准

- 单元级测试 A-01 至 A-09 无阻塞失败；
- 组合级测试 B-01 至 B-08 关键路径通过；

- Template Integrity Checker 仍为 0 Error / 0 Warning；
- Unity Console 无红色 Error。

## 九、本阶段禁止事项

- 禁止重构 `CircuitStateAnalyzer`；
- 禁止重写 `SimulationEngine`；
- 禁止重写 `WorkspaceController`；
- 禁止修改模板 DTO / 保存 DTO 字段名；
- 禁止全局允许同元件端子互接；
- 禁止把检查面板静态分析与画布 RUN 历史状态强行合并；
- 禁止新增 KT 真实秒级计时；
- 禁止新增参数计算；
- 禁止新增自动往返虚拟运动；
- 禁止为了通过自由接线测试而写死模板 ID。
