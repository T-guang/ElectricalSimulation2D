## 7. 已知边界，不作为 V1 阻塞 Bug

1. 检查面板主要是静态拓扑分析，不读取画布历史 RUN。
2. 画布 RUN 可能包含接触器此前吸合形成的历史自锁保持状态。
3. 连续运行、热继保护、正反转等场景中，启动按钮松开后，画布 RUN 与检查面板静态结果可能存在解释差异；检查面板已提供静态分析说明。
4. KT 当前为手动模拟延时：OFF 表示延时未到，ON 表示延时到达，不是真实秒级计时。
5. OffDelay 断电延时当前未纳入完整分析。
6. 当前不做真实电流、电压、启动电流、转速、转矩或功率计算。
7. 当前不是工业级物理仿真或保护整定工具，不接入 ngspice。
8. `motor_self_hold_control` 的 catalog 描述仍含“占位模板”文案；模板结构本身通过验收，建议后续仅修正文案。

## 8. 严重 Bug 与边界区分

### 应阻塞封版的严重 Bug

- 模板加载失败、typeId/端子不存在或 JSON 无法解析。
- Unity Console 出现 compiler error。
- 停止按钮 OFF 后仍保持 RUN。
- 正常星形、三角形、顺序启动无法运行。
- 普通器件允许同元件端子互接。
- KT 未得电但 15/18 导通。
- 星三角冲突被误判为正常运行。

### 不阻塞 V1 的阶段边界

- 静态检查面板不读取画布历史 RUN。
- 启动按钮松开后，画布因自锁保持继续运行。
- KT 使用手动模拟延时。
- 当前不做真实物理参数和真实秒级计时。
